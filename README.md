# everyoption-site

Public site for Every Option (everyoptionmd.com). Cloudflare Pages builds the `site/` folder from `main`.

- `main` is live. It is protected by the `live-gate` ruleset: changes land only through a pull request that Abhishek approves.
- Preview builds are off. Work happens on branches and goes live by PR.
- No tracking pixels or third-party scripts on any page.
- Strategy, decisions and content drafts live in goswami-hq/ai-hq under `projects/platform/`.
